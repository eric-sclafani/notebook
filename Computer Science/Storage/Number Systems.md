`Number systems` are a way to represent quantities using a set of digits or symbols and a base to define the value in each position.

# Base-2 (binary)

`Base-2`  uses only ==1== and ==0== to represent numbers. Each number is a bit, and a group of 8 bits is known as a byte. 

```
00000001  = 1
00010100  = 20
00001111  = 15
```

For more information, see [[Binary & Encoding]].

# Base-8

`Base-8` is an older system that uses numbers ==0 to 7==. The octal numbers are represented by binary numbers when they are grouped in pairs of three.

It was created as a human-friendly shorthand to express binary.

# Base-10 (decimal)

`Base-10` uses digits from ==0 to 9== to represent digits and is one of the most common ways to represent numbers. One possible reason for this popularity is because humans have ten fingers, making it easier for us to perform mathematic operations with our fingers on the fly.

Each digit's value depends on its position (**place value**), which is based on powers of ==10==. 

![[base10_ex1.jpg]]

For fractional numbers, digits after the decimal point represent **negative powers of 10**.

# Base-16 (hexadecimal)

`Hexadecimal` is a more advanced and widely used number system that uses a combination of letters and numbers: ==0 to 9== and ==A to F==. This numbering system was born out of a need to shorthand binary numbers that got too large (i.e. large decimal numbers). It is a way to represent larger numbers using fewer digits.
